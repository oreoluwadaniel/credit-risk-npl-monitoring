# Credit Risk NPL Monitoring

> **Superseded repository:** this case study is now part of the combined [Credit Risk & Banking Analytics Portfolio](https://github.com/oreoluwadaniel/credit-risk-banking-portfolio).

This repository is kept for project history. The combined repository is the version to review for the current portfolio.

## What this project covered

The original analysis looked at:

- Non-performing loan ratios
- Delinquency levels
- Loan and customer segments
- Portfolio exposure
- Vintage performance
- Country-level risk
- Early warning indicators

The work used synthetic lending data and SQL Server.

## Why it was moved

The same lending data was later used for several related credit-risk analyses. Keeping each analysis in a separate repository made the portfolio harder to follow and repeated the same data and setup.

The work is now grouped in one repository so the full credit-risk story can be reviewed in one place.
